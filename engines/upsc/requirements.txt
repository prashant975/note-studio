# The app takes a video link (Google Drive / YouTube / direct URL) and makes the
# transcript itself. ffmpeg + ffprobe must be on PATH: they read the audio
# straight off the remote video, so no video is ever downloaded.
#
# YouTube captions are the fast path (free, no API key, ~2 s).

# For YouTube videos with no captions: fetches the audio track so it can be
# transcribed. Not used by the Drive or direct-URL paths, which stream instead.

# Google Drive and direct/CDN video access reuse `requests` and `google-auth`,
# both already required above — no Drive-specific package is needed.
#

# about 2 hours. Gemini does the same class in minutes through the proxy.
#   pip install faster-whisper
